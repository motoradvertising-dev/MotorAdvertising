01

Objeto del acuerdo

Alcance y propósito del sistema

Diseñar e implementar un bot automatizado que optimice el proceso de facturación mediante la validación, organización y distribución inteligente de documentos entre las áreas de Autorizaciones, Cuentas Médicas y Facturación. El sistema busca reducir errores humanos, acelerar tiempos de validación y garantizar la integridad documental antes del proceso de facturación.

02

03

Lógica de funcionamiento

Flujo principal y escenarios de respuesta
01
Recepción de documentos
El área de Autorizaciones envía los documentos del caso al sistema bot para iniciar el proceso de validación.
02
Análisis y clasificación
El bot analiza el caso, identifica el tipo de servicio y lo valida contra el checklist de documentos requeridos para ese tipo.
03
Resolución del caso
Según el resultado de la validación, el bot ejecuta uno de los dos escenarios disponibles.
Escenario A
Documentación Completa
  • Organiza archivos en Google Drive
  • Genera estructura ordenada del caso
  • Envía correo automático a facturación
  • Marca el caso como listo para facturar
Escenario B
Documentación Incompleta
  • Detecta documentos faltantes
  • Genera respuesta automática a autorizaciones
  • Especifica exactamente qué falta
  • Devuelve el caso a estado pendiente
04

Tipos de servicio y validación

Checklists documentales por categoría

El sistema contempla 4 tipos de servicio, cada uno con su propio checklist documental. El bot identifica automáticamente el tipo de servicio, aplica las reglas de validación específicas y verifica el cumplimiento total antes de avanzar en el flujo.

NOTA
Los checklists documentales deben ser definidos y proporcionados por VIVIR IPS previamente para cada tipo de servicio, como insumo para la configuración del bot.

Pruebas y control de calidad

Proceso de validación previo a entrega

Antes de la entrega final, se realizarán pruebas unitarias sobre cada módulo del sistema con el fin de detectar errores, corregir bugs, garantizar la estabilidad del flujo y validar el correcto funcionamiento en escenarios reales de operación de VIVIR IPS.

Consideraciones adicionales
